# Nightbane — Music

Every music bed is generated from source by `tools/soundforge`, the same way
the art is generated by `tools/pixelforge`. There is no sample library and no
binary input: the organ, the choir, the strings, the taiko and the bells are
all synthesised.

```bash
python3 tools/build_music.py              # rebuild everything
python3 tools/build_music.py boss shop    # or just those tracks
```

Requires numpy. Output is deterministic — a rebuild with no code changes
produces identical files.

## The tracks

| File | Tempo | Length | What it is |
|------|-------|--------|------------|
| `music/menu.wav` | 66 | 8 bars | Title screen. Pedal organ, distant choir, one bell. |
| `music/shop.wav` | 84 | 8 bars | Between waves. Harp, soft strings, celesta motif. No drums. |
| `music/combat_base.wav` | 132 | 16 bars | Wave music: bass, tremolo strings, voices, a violin line in the back half. |
| `music/combat_percussion.wav` | 132 | 16 bars | The drums for the above, faded in on wave intensity. |
| `music/boss.wav` | 150 | 16 bars | Boss encounters. Everything at once. |

All five are in D — natural minor for the menu and shop, harmonic minor once
something is trying to kill you, so the raised C# is what actually signals a
fight. `AudioManager` crossfades between them, and a shared key means those
crossfades land on a related chord instead of on a key change.

`combat_base` and `combat_percussion` are two halves of one arrangement and
must stay the same tempo and the same number of bars: `AudioManager` plays
them together and rides the percussion layer on how dangerous the wave is
(wave number, time elapsed, live enemy count). If their bar lines disagree the
drums walk away from the strings.

## How the loops work

Game music repeats forever, so every track is rendered longer than it is and
the overhang is folded back over the opening (`core.Loop`). The decay of the
last chord is therefore already ringing under the first beat when the loop
comes round, and the seam is inaudible. This is why the reverb tails are not
simply cut off at the end of the file.

Tracks are 32 kHz stereo WAV. Godot compresses them to IMA-ADPCM on import
(see the `.import` files) and `Autoloads/AudioManager.gd` sets the loop points
at load time.

## Sound effects

`sfx/*.wav` are one-shots keyed by the ids registered in
`AudioManager._register_placeholder_sfx`. A missing file is silence-safe: the
id stays registered with a null stream and `play_sfx` simply does nothing.
